# Figma spacing and radius source

- File: [Kofa Foundation](https://www.figma.com/design/BVk88Tno1MTxZiM0k3MToy/Foundation?node-id=9-2)
- Page: `Spacing and Radius` (`9:2`)
- Spacing section: `Spacing` (`9:20`)
- Radius section: `Radius` (`9:201`)
- Imported: 2026-09-06

The spacing system contains 17 values from `spacing-none` (`0px`) through
`spacing-11xl` (`160px`). The radius system contains 11 values from
`radius-none` (`0px`) through `radius-full` (`9999px`).

Token names and values were taken directly from the two foundation tables in
Figma. The former provisional numeric spacing names were replaced by the
approved semantic size names.
